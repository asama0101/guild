# ボード（`guild/board.html`）の設計メモ

依頼主が使う画面。`/guild:init` が `guild/board.html` に置く。正本は `skills/quest/board.html`（1ファイル、外部通信なし）。

## 決めたこと（デザインの検討の結果）

- **1ページで完結**：画面を移らない。上のタブは「掲示板／やりとり／ヘルプ」の3つだけ。
- **掲示板**：上に「あなたの番」の帯と、新しい依頼の入力欄（書いて「出す」の1回で保存）。その下に依頼の一覧（台帳）。選んだ依頼の行が開き、中に「手紙」（いま必要な用件）と「道のり」（Todo の札）が出る。
- **手紙**：計画の承認、あなたの実行（結果の入力）、実行前の確認、失敗の判断、完了。答えは `inbox/` に JSON で書く。
- **やりとり**：依頼を選び（または「すべての依頼」）、「会話の流れ」と「タイムライン（実績の帯）」を切り替える。会話は役ごとに絞り込め、各発言から報告書を開ける。
- **ヘルプ**：使い方、印の見方、言葉の説明、困ったとき、コマンド。
- **見た目**：ギルド調。看板は深紅に金の文字、紙の上に封蝋と朱肉の印。配色は案G1・背景1（羊皮紙）。色は `:root` の変数で持つ。

### 配色（案G1・背景1）

| 変数 | 色 | 用途 |
|---|---|---|
| `--bg` | `#E7DEC9` | ページの背景 |
| `--banner` / `--banner-ink` | `#6E1B28` / `#F0CF7A` | 看板とタブの地・金の文字 |
| `--paper` / `--paper2` | `#F6EEDB` / `#FCF8EC` | 紙・手紙 |
| `--ink` / `--sub` | `#2B2019` / `#5C4A3C` | 本文・補足 |
| `--brass` / `--line` | `#A8863A` / `#CDB98A` | 枠・線 |
| `--seal` / `--gold` | `#7A1E2C` / `#7A1E2C` | 封蝋・見出し・リンク |
| `--ok` / `--warn` / `--ng` | `#2E6B47` / `#7D5200` / `#B3261E` | 合格／あなたの番／できず |

状態は色だけでなく、文字ラベルと線の形（実線・点線・破線・斜線）でも区別できる。

## 読み書きの契約

- 画面が書けるのは `guild/` の中の次の場所だけ。`plan.json` は書かない（書くのは `guild.py` だけ）。
  - `requests/R<日時>.json`（新しい依頼。素材は `requests/files/R<日時>/`）
  - `Q###/inbox/<日時>-<種類>[-<Todo>].json`（承認・直す・中止・確認・結果・判断。添付は `inbox/files/`）
- 反映は、依頼主がチャットで「完了」と伝えたあと、ギルドマスターが `guild.py ingest` で行う。
- 画面は3秒ごとに `guild/` を読み直す。読むのは `Q###/plan.json`（状態と `history`）、`reports/`、`output/`、`inbox/`、`requests/`、`knowledge/`。
- タイムラインと会話は、`plan.json` の `history`（`guild.py` が状態を変えるたびに時刻つきで追記する）から作る。

## 動作環境と制約

- **Chrome または Edge**：フォルダへの書き込み（File System Access API）を使う。Firefox・Safari では保存できない。
- **許可はブラウザを開き直すたびに求められる**ことがある。画面の「再接続する」で許可する。
- **保存に失敗したとき**は、理由を画面に出し、送る内容を「コピー」できる形で見せる（チャットに貼る）。
- フォルダを覚える入れ物（IndexedDB）が壊れていても、作り直して続ける。覚えられなかったときは、理由を出す。
- **見本**：`board.html?demo=human`（ほかに `plan`・`confirm`・`failed`・`done`）で、保存せずに見られる。
