# 簡易日本語の規則と語彙表（STE 着想）

ASD-STE100 は英語の規格で、公式の日本語版はない。guild は、依頼主の決定で**日本語に翻案**し、「STE 着想の簡易日本語」と呼ぶ。SPEC 12 節の規則を、ここに詳しく置く。

## 適用範囲
- 適用する：依頼主向けの出力（クエスト票、質問、受付嬢の返答、図の文言、知らせ）と、画面の固定文言（ボタン、見出し、説明）。
- 適用しない：内部ファイル（依頼書、報告書、掟、教訓帳）、ログ、冒険日誌。

## 規則
1. 1 文に 1 つの内容。40 字を目安にする。
2. 主語と述語を書く。
3. 指示語（これ・それ・あれ）を使わない。
4. 能動態で書く。
5. 手順は、1 文に 1 つの動作。
6. 曖昧な語（適宜・など・いろいろ）を使わない。
7. 日付は「3月8日」の形にそろえる。
8. 用語は語彙表で 1 語 1 義。同じものを別の語で言い換えない。

機械の検査（`board.py lint-text`）は 0.3 で入る。主語の有無は機械では確かめられない。

## 語彙表
| 内部の言い方 | 依頼主に見せる言い方 |
|---|---|
| 承認① | 道のりの承認 |
| 承認② | 納品物の承認（納品物の確認） |
| 承認③ | 実行の承認 |
| 不可逆な操作／実行・投入 | 元に戻せない操作／実行（外へ出す） |
| 同時数 | 同時に進める数 |
| ガント | 予定表 |
| 余裕 | ゆとり |
| 合否 | 結果 |
| 直す | 承認画面では「やり直す」、魔導書では「修正する」 |
| 保留（選択肢） | あとで決める |
| 保留（状態） | 止めている |
| 作業・検査 | 冒険者の作業は「作業」、鑑定士の検査は「鑑定」 |
| じっくり | 念入りに作る |
