# /guild:help

次の内容を、簡易日本語で、依頼主に説明する（1 文に 1 つの内容、40 字目安、指示語と曖昧語を使わない）。長く書かない。

## guild とは
依頼を出すと、ギルドの仲間（役ごとのサブエージェント）が分担して片付け、納品物を納める。あなたがすることは、依頼を出すこと、承認すること、聞かれたことに答えることだけ。

## 使い方
1. `/guild:init` で、vault に `guild/` を作る（最初の 1 回）。
2. `guild/board.html` を Edge か Chrome で開き、`guild/` フォルダを選ぶ。
3. 画面の「クエスト」のタブで、依頼を出す。
4. `/guild:quest` を実行する。1 回で、進められるところまで進む。`/guild:quest auto` は、確認なしで進める（承認は自動で進まない）。
5. 会話しながら納品物を作りたいときは、`/guild:workshop` を使う。素材を足し、一緒に下書きを直せる。
6. 画面の先頭に「いま何をするか」が出る。質問に答え、道のりと納品物を承認する。

## 流れ
依頼 → 達成条件に分ける → 道のりを決める → **道のりの承認（あなた）** → 冒険 → 鑑定 → **納品物の承認（あなた）** → 達成。
元に戻せない操作があるときだけ、**実行の承認（あなた）** が増える（その操作は、あなたが承認したあとに実行する）。

## 状態の見方
- クエスト：聞き取り中／計画を作っている／あなたの承認を待っている／進めている／全体を確かめている／達成／達成できなかった／中止／止めている。
- 達成条件：計画の案／順番を待っている／冒険者が作業している／鑑定士が確かめている／直している／あなたの確認を待っている／あなたの実行の承認を待っている／達成。
- クエストのフォルダの `quest.md`（クエスト票）に、進み方が書いてある。

## 質問と期限
- 質問には、おすすめの答えが付く。期限（3 日）が来ると、おすすめの答えで進む。
- **承認は、あなたが押すまで進まない。** 期限が来たら、画面と `quest.md` に「承認待ちです」と出る。
- 「あとで決める」を選ぶと、質問は残る。

## ギルドの仲間
受付嬢（聞き取り）／占い師（分解）／冒険者（事実の収集）／錬金術師（納品物の中身）／鍛冶師（Word・Excel などの器）／鑑定士（結果の判定）／魔法使い（魔導書）／吟遊詩人（教訓と人物伝）。

## 覚えていくこと
- **魔導書**：業務用語・設備・取り決め。魔法使いが候補を書き、あなたが確定する。
- **人物伝**：あなたの好み。吟遊詩人が案を書き、あなたが確定する。
- **掟**：同じ指摘が 2 回出たら、足すかどうかを聞く。
- **資料室**：複数のクエストで使う素材。画面から足せる。
- **設計図**：会社のひな形。出来のよい納品物を、ひな形にできる。
- クエスト票の中の「予定表」で、締切と、間に合わないおそれのあるものが見える。
- 「資料室・設計図・魔導書」のタブで、共有の素材、会社のひな形、覚えた用語と取り決めを見られる。ひな形（Word・Excel・PowerPoint・PDF）は、画面から足せる。

## 画面の見方
- **使い方**：この説明と、同時に進める数（1〜8）の設定。
- **クエスト**：依頼を出す欄、ギルドからの知らせ、かんばん、クエスト票（目的・達成条件・予定表・記録・あなたがすること）。クエストを選んで絞れる。
- **質問**：答える質問を全部表示する。クエストと種類で絞れる。おすすめの答えのほかに、「どれでもない」と書いて答えられる。
- 帯の下の「あなたの番」に、あなたがすることが出る。どのタブでも見える。

## 入れたデータの扱い
入れたデータは、取り扱ってよいものとして扱う。トークン・鍵・パスワードを入れるかどうかは、あなたが決める。guild は、中身を検査して止めない。

## 自動実行
依頼主が頼んだときだけ、`guild/.system/auto/guild-run.py --install` で、OS のスケジューラに登録する。進める作業がないときは、Claude を呼ばない。進まない状態が 2 回続くと止まる。
