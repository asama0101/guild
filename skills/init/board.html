ギルドの扉

vault の中の guild フォルダを選んでください。掲示板はそのフォルダを読み書きして、ギルドマスターとやりとりします。

Microsoft Edge か Google Chrome で開いてください（Firefox ではフォルダの読み書きができません）。扉は 1 回開けば、タブを行き来しても出ません。

動かし方

  1. /guild:init でギルドを作ります（済んでいれば、この画面が開けています）。
  2. この画面で、依頼（クエスト）や研究を貼ります。ここに出る質問にも答えます。
  3. Claude Code で /guild:quest を実行すると、ギルドマスターが依頼を受け取り、ギルド員が動きます。
  4. 自動で回したいときは /guild:auto 始める。決めた間隔で、ギルドが自分で /guild:quest を動かします。

依頼や返事は、次に /guild:quest が動いたとき（手で実行するか、自動実行の次の回）にギルドマスターが受け取ります。

止め方

  • 自動実行を止める：/guild:auto 止める
  • いま実行中の /guild:quest を止める：Claude Code の画面で Esc を押します。
  • 止まったまま残った錠 guild/.system/auto/run.lock は、1 時間より古ければ消してかまいません（1 時間以内なら、どこかで回が動いています）。

状態の見方

クエストの状態
受付待ち 貼ったばかりで、まだギルドマスターが受け取っていません。
受付済 受付が済み、冒険者を待っています。
冒険中 ギルド員が作業中です。鑑定中 は、結果を鑑定士が確かめています。
要手直し 鑑定で足りないところが見つかり、直しています。
返事待ち あなたの返事を待っています（「返事が要るもの」タブ）。
依頼主がやること あなたにしてほしい作業です。
達成 終わりました。結果の評価（Good / Bad）を送れます。
中止 取り消されました。
研究の状態
受付待ち → 計画中 → 承認待ち（計画を承認すると動き出します）→ 進行中 → 達成。
返事の色
赤い丸は、まだ返事をしていない質問の数です。返事を送ると、カードが緑の枠と「✓ 返事済み（受け取り待ち）」の帯になり、次の回で受け取られると消えます。

用語

ギルドの扉
vault の guild フォルダを、この画面につなぐこと。1 回開ければ、タブを移っても出ません。
ギルドマスター
依頼を受け取り、ギルド員に割り振る親玉。/guild:quest の 1 回ごとに動きます。
クエスト
1 つの作業の依頼。貼る → 受付 → 冒険 → 鑑定 → 達成と進みます。
研究
いくつものクエストにまたがる目標。計画を承認してから動き出します。
段
研究の中のクエストを、前提の順に並べた列。同じ段のクエストは同時に進められます。
錠（run.lock）
自動の回が重ならないようにする目印のファイル。
人物帳
依頼主（あなた）のことを書きためたノート guild/client.md。どのギルド員も依頼のたびに読みます。
