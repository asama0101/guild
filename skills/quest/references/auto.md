# 自動実行の回（引数 `auto`）と許可が断られたとき

## 錠
- 自動の回（`/guild:auto` が決まった間隔で起こした回）では、錠 `guild/.system/auto/run.lock` はスクリプトが作って消す。あなたは触らない。
- 手で実行した回は、`guild/.system/auto/` があるときだけ：`run.lock` が 1 時間以内なら自動の回が動いているので、終わってからもう一度実行するよう伝えて止まる。1 時間より古ければ残りなので消してよい。始めに `run.lock` を作り（中身は今の日時）、締め（手順 11）のあとに消す（途中で止まるときも）。手順 2・5・7・11 の始めに日時を書き直す（1 時間を超える回でも自動の回と並走しないため）。

## 自動実行のとき
依頼主は画面の前にいない（回ごとの使用量は `guild/.system/logs/usage.jsonl` にスクリプトが記録する。あなたは書かない）。Claude Code の許可が要る操作（許可されていない道具、許可の一覧に無いコマンド）は断られて止まる。
- 止まったら、待たずにそのクエストを（`冒険中`・`鑑定中` どちらでも）`返事待ち` にする。何の許可が要るか（道具やコマンドの名前）と、許可のしかた（`/guild:auto` の許可の一覧 `guild/.system/auto/allow.txt` に足すか、手で `/guild:quest` を実行して許可する）を、伝令の取り次ぎで質問に載せ、知らせにも書く。
- クエストが無い場面（研究の計画・直し、評価の聞き取り、インタビュー、賢者・司書）で断られたときは、状態を動かさず、`study_id`／`feedback_id`／`interview_id` 付きの質問（伝令の取り次ぎ。賢者・司書ならどちらも付けない）で許可を聞き、`resume` で次の回に続ける。
- 依頼主に Claude Code の画面で答えてもらう前提の進め方はしない。
- board.py が動かせない許可で止まったら、`guild/.system/python.txt` の Python が `allow.txt` に `Bash(<python>:*)` として無いのが原因。`/guild:auto 始める` を入れ直すと足される、と案内する。
